wxReader

> Download > Screenshots > GitHub Repo

An open-source lightweight reader for comic, manga, and magazine reading in zip, pdf, ePub, and more. Built with wxPython, PyMuPDF, OpenGL, libvips, and Python. It is compiled by Nuitka and distributed as a portable Windows app.

Language support currently: en_US, ja_JP, zh_SG, zh_HK and zh_TW. Machine translation was used as an auxiliary tool for translations into languages other than English.

Features

  • Two-page spread support with blank-page padding
  • Gallery mode for a quick overview
  • Light mode and dark mode
  • Mouse quick-action wheel
  • Multi-tab reading
  • Custom GLSL shader effects and effect groups
  • (Optional) voice and webcam eye-gesture controllers
